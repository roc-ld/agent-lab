# 返工的增量复验（不是阶段放行）

本发行版保留完整阶段放行，增量集用于在下一轮独立探索前快速暴露修复错误。使用 workflow.py run 在独占资源内运行，以事件记录区分机器重放与 AI 探索。

顺序：逐问题复验 → 相关构建/单测 → 成熟回归包重放 → 受影响业务链路。根据实际 diff、后端接口、数据表、共享组件与需求锚点确定影响，不能只匹配页面目录。权限、状态机、迁移、跨域协议、共享组件、检查器改变或映射不完整时扩大到完整范围。

缺陷复现探针先转换成正向不变量：修好后应绿、重新引入缺陷应红。用户 id、时间、输出文件不能使用另一次运行的常量；每组明确 reset/seed 边界，禁止残留数据决定红绿。检查集从相同快照重复运行应稳定；不把期望缺陷仍存在的探针直接纳入回归。

局部通过后 issue repair 记录根因、当前版本、局部日志，再 qa start 做完整独立 L0–L3。本版没有“复用旧分片 PASS”的入口，也不自动根据不完整 touches 缩小最终范围。

后续如要启用自动增量放行，须另发版本：先建立机器可审计的依赖映射、证据失效规则，在历史快照和试点中与完整 QA 对照；不能在本版固定目录热切换策略。
